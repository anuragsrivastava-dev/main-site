## 🚀 How to Link Your Custom Domain

1. **Point DNS**:
   - If hosting on GitHub Pages: Add a `CNAME` record in your DNS provider pointing to `anu69-web.github.io`.
   - Add a `CNAME` file in this directory containing your domain name (e.g. `yourdomain.com`).
2. **Launch locally for testing**:
   - Simply open `index.html` in any modern web browser or run `npx serve .` inside `main-site/`.
